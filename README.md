# Electricity Consumption Analysis

## 📊 Project Overview

Electricity Consumption Analysis is a Power BI project developed as part of a Davis training class.

The project focuses on analyzing electricity consumption data and creating an interactive dashboard to understand consumption patterns through data visualization and analysis.

## 🎯 Objectives

- Analyze electricity consumption data.
- Clean and transform data using Power Query.
- Create meaningful visualizations in Power BI.
- Identify patterns and trends in electricity consumption.
- Build an interactive dashboard for data exploration.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📈 Dashboard

The project includes an interactive Power BI dashboard with visualizations designed to explore electricity consumption data.

The dashboard allows users to analyze the available data using charts, filters, and interactive elements.
